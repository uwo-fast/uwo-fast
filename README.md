# uwo-fast

Welcome to the UWO-FAST General Repository. This repository is a centralized hub for various resources, guidelines, and tools to support our research group. Below is an overview of the contents.

When you go to make a new repository and select from template. Currently FAST has the following templates to choose from:

- [github.com/uwo-fast/repo-template](https://github.com/uwo-fast/repo-template)

## Contents

- [`lab-signs/`](lab-signs/) — the printed safety signs posted in the lab, built to
  PDF by `just build` and published at <https://uwo-fast.github.io/signs/>.
- [`equipment/`](equipment/) — reference records for specific equipment: nameplate data,
  specifications, operating limits. Not printed.
- `agri-tunnel-sign/`, `teb-6-7-layout/`, `printing-profiles/`, `lab-qr-codes/` — asset
  stores, nothing to build.

Run `just` to see the available commands.

## Ordering

Send what you need to Dr. Pearce to be ordered. Use the group BOM template, with one
exception: for McMaster-Carr, DigiKey or Mouser, send a cart link instead.

## DI water

FAST does not produce its own. Ask the lab across the hall in TEB28.
